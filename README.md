# Olá 👋

Desenvolvedor de software: aplicativos Android, backend em C# e nuvem, agentes de inteligência artificial e sistemas embarcados em Linux.

## No que estou trabalhando

- 🚁 **fpvcast**: um receptor de vídeo FPV em C para Raspberry Pi. O Pi se passa por um celular Android, recebe o
  H.264 dos óculos DJI pela USB e mostra no HDMI com decodificação na GPU, com cerca de 27 ms de latência no
  decodificador. Inclui interface web de configuração, ponto de acesso Wi-Fi de emergência e imagem pronta para
  gravar no cartão.
- 📚 Estudando agentes de IA, engenharia de prompt, streaming de vídeo de baixa latência (RTMP, WebRTC) e Linux embarcado.

- 🧠 [**prompt-eng**](https://github.com/albeson/prompt-eng): scripts em Python que comparam técnicas de engenharia de prompt, do prompt direto a chain, skeleton e tree of thought, até um agente ReAct.
